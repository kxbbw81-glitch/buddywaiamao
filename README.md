# NexFab AI CRM V2.0

NexFab AI CRM 的 V2.0 发布基线，包含外贸 CRM 后端、Prisma PostgreSQL 迁移、接口 smoke 测试、前端预览和交接资料。

- 后端代码与运行说明：[`backend/README.md`](backend/README.md)
- V2.0 需求基准：[`docs/requirements-v2.md`](docs/requirements-v2.md)
- 验证记录：[`backend/VALIDATION.md`](backend/VALIDATION.md)

AI 能力仅提供受控的本地草稿、策略、审计和人工确认闭环；接入第三方模型服务时，需由使用方自行配置并承担服务费用。
